Blueprint / Direction A

同一产品语言，双端统一成品

正式版不再把安卓和网页当成两套分裂系统，而是做成一套面向家庭场景的产品。 孩子端负责轻量执行，家长端负责布置、审核、统计与通知；两端共享同一套账户、任务、积分、媒体交付、报表与通知能力。

Visual Thesis 轻盈、温和、像学习工具而不是厚重管理台
Content Plan 任务执行最突出，积分与反馈次之，统计与配置后置
Interaction Thesis 开始动作要自然，交付动作要像系统相机/录音，不像表单

首发正式版目标

安卓端完整可用
网页后台可选启用
部署方式Docker 开关化
开源导向默认多家庭可用

产品结构

正式版拆成 5 个清晰模块，每个模块都有稳定边界，后面扩展时不会互相打架。

01 / Identity

账户与家庭体系

支持家长自助注册、管理员创建家长、家长添加孩子；孩子默认用户名 + PIN，也可邮箱 + 密码。

02 / Tasks

任务与交付体系

任务可配置直接打卡、倒计时、手动计时，并可配置无要求 / 照片 / 视频 / 音频交付，以及上传即完成或待家长审核。

03 / Points

积分、兑换与账本

自动积分、家长手动调整、孩子发起自定义积分兑换、家长审核、兑换比例与最低兑换门槛家庭级配置。

04 / Reporting

日报 / 周报 / 月报

按孩子、按任务、按时间维度输出完成率、平均用时、趋势变化、兑换行为与效率波动。

05 / Notify

通知与部署开关

支持钉钉 Webhook 与通用 Webhook；网页后台模块在 Docker 中可开启或关闭，不影响安卓端主流程。

核心数据流

这条流是正式版的主骨架，孩子端体验和家长端后台都围绕它展开。

步骤 1
孩子端 开始任务

根据任务模式开始计时或直接进入交付动作。

家长端 提前配置规则

设置时间、交付条件、积分、审核方式、提醒方式。

步骤 2
孩子端 拍照 / 录像 / 录音 / 相册选择

交付动作直接调用系统能力，完成后自动上传。

后端 保存媒体与提交记录

存储文件、写入 submission、记录北京时间精确时间与保留期。

步骤 3
系统规则 自动完成或转待审核

按任务配置决定是立即完成发积分，还是进入家长审核队列。

家长端 查看、审核、复盘

能看交付内容、完成时间、耗时、积分变化，以及趋势报表。

首个正式版边界

  • 不是先做一个“看起来像正式版”的演示壳，而是直接做真实可部署产品。
  • 安卓端与网页后台共享同一后端与同一数据模型，不做双份业务逻辑。
  • 媒体交付是正式版核心能力，不再允许用占位按钮代替。
  • 网页后台默认可选启用，Docker 配置关闭时，安卓主系统仍可独立工作。
