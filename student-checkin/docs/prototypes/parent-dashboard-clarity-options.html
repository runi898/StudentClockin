Parent Console / Clarity Options

家长端要直观看到每个孩子，但不能乱

家长端最容易做成“信息很多但不好扫”的后台。真正合适的做法，是让每个孩子都有可见度，但只把最需要处理的内容放到主区，把其他信息压缩成概览。

推荐
Option A

孩子概览条 + 焦点工作区

顶上一排直接看到每个孩子的今日完成情况，下面主区只显示当前最需要处理的任务、审核和异常。

优点

  • 每个孩子都能第一眼看到，不会被藏起来。
  • 主区只展示最该处理的内容，不会把页面堆满。
  • 最适合 2 到 5 个孩子的家庭场景。
最平衡的正式版方案 既能快速扫每个孩子，又不会像报表后台一样杂乱。
Option B

左侧孩子标签页

左边是孩子列表，右边只看当前选中的一个孩子，适合每次只想专注看一个孩子的家长。

优点

  • 单个孩子的信息最完整、最干净。
  • 适合逐个孩子细看。
  • 移动端和平板端改造也容易。
更偏“详情页”思路 它很整洁，但第一眼不如方案 A 那样能同时扫到全部孩子。

孩子矩阵总览

把每个孩子做成一张小面板并排展示，像总控台，适合孩子很多时快速横向比较。
