Task List / Clarity Options

任务列表当然可以更直观

真正需要解决的不是“任务显示成几列”，而是三件事：还剩哪些没做、下一步先做什么、今天整体进度到哪了。 我把最适合孩子端的 3 种任务列表方案并排放出来，你选一个主方向，我后面就按这个做正式版。

最上面先告诉你今天完成多少、还差多少，然后把“还没做”的任务全部排在前面，已完成折叠到下面。

优点

  • 第一眼就知道今天还差几项。
  • 孩子最容易理解，不会被已完成任务干扰。
  • 家长查看时也能马上定位未完成任务。
最适合正式版首发 它把“进度感”和“未完成感”放到最前面，兼顾孩子端执行和家长端查看。
